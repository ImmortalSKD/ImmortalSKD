## 🟣 About Me

<img align="right" alt="coding" width="280" src="https://raw.githubusercontent.com/devSouvik/devSouvik/master/gif3.gif"/>

I'm an **Electronics & Communication Engineering** undergraduate at **University Institute of Technology, Burdwan University**, working at the intersection of **embedded hardware** and **artificial intelligence**.

My core focus is designing **STM32-based embedded systems** — from schematic to a working 4-layer PCB — and pairing that hardware foundation with **AI-assisted engineering workflows** using Python, LLMs, and modern developer tooling. I'm especially interested in where **Embedded AI** and **IoT** meet: intelligent hardware that can reason, not just sense and actuate.

Beyond the bench, I lead sponsorship and collaboration efforts for **PPGS**, coordinating partnerships and large-scale event logistics — leadership experience that shapes how I approach technical project ownership.

**🔭 Currently exploring:** Embedded AI architectures, ESP32 + cloud LLM integration, and AI-accelerated hardware development.

## 🟣 Featured Projects

<details>
<summary><b>🔷 STM32H743 Professional Development Board</b></summary>
<br/>

A custom-designed development board built around the STM32H743, engineered as a full-featured embedded platform rather than a bare-bones eval board.

**Technical Overview:** The board integrates SDRAM for extended memory-intensive applications, SPI Flash for firmware and data storage, native USB connectivity, an SWD interface for debugging/programming, and a dedicated power management subsystem — all routed on a 4-layer PCB for improved signal integrity and thermal performance.

| Attribute | Details |
|---|---|
| **Stack** | STM32H743, SDRAM, SPI Flash, USB, SWD |
| **PCB** | 4-layer, EasyEDA / Altium Designer |
| **Focus** | Power management, high-speed signal routing, debug interface design |
| **Status** | Completed |
| **Future Scope** | Add onboard Ethernet & expand peripheral breakout headers |

</details>
